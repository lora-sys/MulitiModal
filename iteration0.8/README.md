# Iteration 2.5: 多模态舒适度预测模型

## 项目概述

本项目完成了按摩椅多模态数据的时序对齐、特征提取、融合和模型训练，实现了基于压力和心率信号的舒适度预测。

---

## 核心挑战

### 多模态时序对齐

| 模态 | 采样率 | 时间戳特点 |
|------|--------|-----------|
| 压力传感器 | 50Hz | 整齐 (0, 0.02, 0.04...) |
| 心率传感器 | 1Hz | 抖动 (0.989, 1.454, 2.625...) |

**问题**: 50Hz和1Hz信号无法直接对齐，合并后满是NaN。

**解决方案**: `pd.merge_asof` + 三次样条插值

## 三个版本的演进

### V1: 简单标签版

**标签生成方式**: 仅基于压力强度

```python
if pressure < 45: label = 1.0      # 舒适
elif pressure < 65: label = 0.5    # 一般
else: label = 0.0                  # 不舒适
```

**特征数量**: 12个 (压力5 + 心率5 + CPI1 + 其他)

**心率特征贡献**: ~2.5%

**问题**: 标签只考虑压力，心率完全没参与决策，心率特征白加。

---

### V2: 心率特征增强版

**改进**: 新增4个心率特征

```python
# 新增心率特征
hrv_change      # HRV变化率（二阶差分标准差）
hr_local_std    # 局部标准差（最后50个点）
hr_response_amp # 响应幅度（最大-最小）
hr_deviation    # 平均偏离度
```

**特征数量**: 16个 (压力5 + 心率9 + CPI1 + 其他)

**心率特征贡献**: ~3.0%

**问题**: 标签仍只考虑压力，心率特征贡献提升有限。

---

### V3: 综合标签版 ✅

**标签生成方式**: 综合判断（压力+心率+耦合关系）

```python
舒适度 = 0.35×压力评分 + 0.25×心率评分 + 0.15×稳定性 + 0.25×耦合关系
```

**标签计算公式详解**:

1. **压力评分** (35%)
   - 30-60: 舒适区间
   - <30: 太轻 (扣分)
   - >70: 太重/疼痛 (扣分)

2. **心率评分** (25%)
   - 60-80: 正常心率
   - <60: 偏慢 (扣分)
   - >100: 偏快 (扣分)

3. **稳定性** (15%)
   - 压力波动大 = 不舒适
   - 心率波动大 = 不稳定

4. **耦合关系** (25%) - 核心创新
   | 压力趋势 | 心率趋势 | 耦合评分 | 含义 |
   |---------|---------|---------|------|
   | ↑ 上升 | ↓ 下降 | 1.0 | 放松反应 (好) |
   | ↑ 上升 | ↑ 上升 | 0.2 | 疼痛/紧张 (坏) |
   | ↓ 下降 | 任意 | 0.8 | 压力释放 (好) |
   | 稳定 | 稳定 | 0.7 | 平稳状态 |

**特征数量**: 16个 (压力5 + 心率9 + CPI1 + 其他)

**心率特征贡献**: ~25% ⬆️⬆️⬆️

## 关键发现

### ✅ 成功之处

1. **心率特征贡献大幅提升**: 从2.5% → 25%
2. **真正实现多模态融合**: 心率参与标签决策

2. **异常场景敏感**: 噪声和痛感响应场景预测较差

### 💡 改进方向

1. 增加训练数据量 (300+ 样本)
2. 注入更多异常样本进行数据增强
3. 使用多延迟训练数据提升泛化能力
