# 工业级数据生成器代码详解 (Simulation 3.0)

## 📋 概述

本文档详细解释 `generate_industrial_data.py` 的核心逻辑，该脚本用于生成1000人规模的工业级噪声数据，注入3种恶性噪声以测试模型鲁棒性。

---

## 1️⃣ 配置参数部分

```python
BASE_PATH = "./data/industrial"  # 数据输出路径
CATEGORIES = {"身体表征很差": 0, "身体表征一般": 1, "身体表征正常": 2, "身体表征良好": 3}
PEOPLE_PER_CAT = 250  # 每类250人，总计1000人
FS = 50  # 采样率 50Hz（每秒50个数据点）
DURATION = 20  # 持续时间 20秒
```

### 关键理解
- **4个类别**：身体表征从"很差"到"良好"，标签0→3递增
- **数据规模**：250人 × 4类 = 1000人
- **信号长度**：20秒 × 50Hz = 1000个数据点/人

---

## 2️⃣ 步骤1：生成基础物理参数

```python
height = np.random.randint(155, 190)  # 身高 155-190cm
weight = int(height - 105 + np.random.normal(0, 5))  # 体重
hr_base = 70 + (3 - label) * 10 + np.random.randint(-5, 5)  # 心率
spo2_base = 98 - (3 - label) + np.random.randint(-1, 1)  # 血氧
```

### 物理规律解释

| 参数 | 计算公式 | 物理意义 |
|------|---------|---------|
| **身高** | 155-190cm随机 | 正常成年人体重范围 |
| **体重** | 身高-105 + 噪声 | 标准体重公式，加±5kg波动 |
| **心率** | 70 + (3-label)×10 + 噪声 | 身体表征差→心率高（紧张） |
| **血氧** | 98 - (3-label) + 噪声 | 身体表征差→血氧低 |

### 举例说明
- **身体表征很差**（label=0）→ 心率 = 70 + 30 = **100 bpm**（偏高）
- **身体表征良好**（label=3）→ 心率 = 70 + 0 = **70 bpm**（正常）

---

## 3️⃣ 步骤2：生成时间序列

```python
t = np.linspace(0, DURATION, DURATION * FS)
```

### 生成结果
- `t = [0.0, 0.02, 0.04, 0.06, ..., 19.98]`（1000个点）
- 每个点间隔 = 1/50 = 0.02秒

---

## 4️⃣ 步骤3：计算压力信号基础参数

```python
p_offset = weight * 0.6  # 压力基准
p_amplitude = 15 + label * 8  # 振幅
```

### 物理定律

| 参数 | 公式 | 含义 |
|------|------|------|
| **p_offset** | 体重 × 0.6 | 体重越重，压力基准越大 |
| **p_amplitude** | 15 + label × 8 | 身体表征越好，按摩力度越大 |

### 举例说明
- 体重70kg → 压力基准 = 70 × 0.6 = **42**
- 身体表征良好（label=3）→ 振幅 = 15 + 24 = **39**

---

## 5️⃣ 步骤4：注入工业级噪声（核心！）

### 📌 噪声1：强力底噪

```python
noise = np.random.normal(0, 8.0 - label * 1.5, len(t))
```

#### 解释
- **来源**：高斯噪声（正态分布）
- **方差**：8.0 - label × 1.5
- **物理意义**：身体表征好的人，按摩力度大，底噪相对较小

#### 各类别噪声强度

| 类别 | label | 噪声方差 | 噪声强度 |
|------|-------|---------|---------|
| 身体表征很差 | 0 | 8.0 | 很强 |
| 身体表征一般 | 1 | 6.5 | 较强 |
| 身体表征正常 | 2 | 5.0 | 中等 |
| 身体表征良好 | 3 | 3.5 | 较弱 |

#### 效果
在原始信号上叠加随机波动，模拟传感器电子噪声。

---

### 📌 噪声2：接触不良跳变

```python
spikes = np.zeros(len(t))
spike_idx = np.random.choice(len(t), int(len(t) * 0.002))
spikes[spike_idx] = np.random.uniform(50, 100, len(spike_idx))
```

#### 详细拆解

1. **初始化**：`spikes = [0, 0, 0, ..., 0]`（1000个零）
2. **选择跳点位置**：
   - 概率：0.2% = 0.002
   - 数量：1000 × 0.002 = **2个跳点**
   - 位置：随机选择（如第123、第789个点）
3. **生成跳点幅度**：
   - 范围：50-100（瞬间爆表）
   - 例如：`spikes[123] = 75`, `spikes[789] = 88`

#### 物理意义
- 模拟传感器接触不良
- 瞬间信号爆表或掉线
- 这是"恶性噪声"，会严重影响特征提取

---

### 📌 噪声3：基线漂移

```python
drift = 5 * np.sin(2 * np.pi * 0.01 * t)
```

#### 参数解析

| 参数 | 值 | 含义 |
|------|-----|------|
| **幅度** | 5 | 漂移范围 ±5 |
| **频率** | 0.01 Hz | 周期 = 1/0.01 = **100秒** |
| **波长** | 100秒 | 20秒内只完成 1/5 个周期 |

#### 效果可视化
```
时间：    0s    5s    10s   15s   20s
漂移：    0   +3.5  +5   +3.5   0   （正弦波）
```

#### 物理意义
- 模拟传感器温漂（温度变化导致零点漂移）
- 模拟用户坐姿缓慢挪动
- 这是最难检测的噪声（缓慢变化）

---

## 6️⃣ 步骤5：生成双传感器压力信号

```python
# 传感器1：主传感器
p1 = p_offset + p_amplitude * np.sin(2 * np.pi * 0.5 * t) + noise + spikes + drift

# 传感器2：从传感器（相位偏移+幅度缩放）
p2 = p_offset * 0.9 + p_amplitude * np.sin(2 * np.pi * 0.5 * t + 0.1) + noise + spikes + drift
```

### 信号组成

| 分量 | 传感器1 | 传感器2 | 说明 |
|------|---------|---------|------|
| **基准** | p_offset | p_offset × 0.9 | 从传感器压力稍小 |
| **正弦波** | sin(0.5Hz × t) | sin(0.5Hz × t + 0.1) | 相位偏移0.1弧度 |
| **噪声** | noise | noise | 相同噪声（同步干扰） |
| **跳点** | spikes | spikes | 相同跳点（同时故障） |
| **漂移** | drift | drift | 相同漂移（环境变化） |

### 为什么用两个传感器？
- 提供冗余备份
- 可以交叉验证
- 提高鲁棒性

## 🎯 总结：三种噪声的"杀伤力"

| 噪声类型 | 强度 | 难度 | 对模型的影响 |
|---------|------|------|------------|
| **强力底噪** | 中等 | 低 | 降低特征提取精度 |
| **接触不良跳变** | 极高 | 高 | 导致严重错误预测 |
| **基线漂移** | 低 | 极高 | 隐蔽且难以修复 |
