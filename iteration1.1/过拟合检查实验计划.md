# 过拟合检查实验计划

## 🎯 实验目标

**核心问题**：模型在仿真数据上达到100%准确率，是因为真的学到了规律，还是因为仿真数据的逻辑太清晰？

**关键假设**：
- 如果4个类别的点云完全分离 → 模型学到了真实规律 ✅
- 如果点云有重叠但模型仍100% → 可能学到了模拟器的随机种子规律 ⚠️

---

## 📊 实验设计

### 实验1：PCA降维散点图（2D可视化）

**目的**：在高维空间中可视化4个类别的分布

**方法**：
1. 使用PCA将16个特征降维到2个主成分
2. 绘制散点图，用不同颜色标记4个类别
3. 观察点云是否分离

**预期结果**：
- ✅ **正常情况**：4个颜色的点云明显分离，边界清晰
- ⚠️ **异常情况**：点云有重叠，边界模糊

**代码要点**：
```python
from sklearn.decomposition import PCA

# 降维到2D
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X[features_full])

# 绘制散点图
plt.scatter(X_pca[y==0, 0], X_pca[y==0, 1], c='red', label='很差')
plt.scatter(X_pca[y==1, 0], X_pca[y==1, 1], c='orange', label='一般')
plt.scatter(X_pca[y==2, 0], X_pca[y==2, 1], c='green', label='正常')
plt.scatter(X_pca[y==3, 0], X_pca[y==3, 1], c='blue', label='良好')
```

### 实验2：t-SNE降维散点图（非线性可视化）

**目的**：使用非线性降维方法，发现PCA可能忽略的复杂结构

**方法**：
1. 使用t-SNE将16个特征降维到2D
2. 绘制散点图，观察类别分离情况

**预期结果**：
- ✅ **正常情况**：t-SNE和PCA都显示类别分离
- ⚠️ **异常情况**：t-SNE显示重叠，但PCA分离（说明有非线性关系）

### 实验3：特征分布直方图（单特征分析）

**目的**：检查每个特征在4个类别上的分布是否重叠

**方法**：
1. 对每个核心特征（std, ptp, hr, spo2）
2. 绘制4个类别的分布直方图
3. 计算类别间的重叠度

**预期结果**：
- ✅ **正常情况**：4个类别的分布有明显的峰值分离
- ⚠️ **异常情况**：分布大量重叠，难以区分

**重叠度计算**：
```python
def calculate_overlap(dist1, dist2):
    """计算两个分布的重叠度"""
    min_val = min(np.min(dist1), np.min(dist2))
    max_val = max(np.max(dist1), np.max(dist2))
    x = np.linspace(min_val, max_val, 1000)
    kde1 = gaussian_kde(dist1)(x)
    kde2 = gaussian_kde(dist2)(x)
    overlap = np.minimum(kde1, kde2).sum() / np.maximum(kde1, kde2).sum()
    return overlap
```

### 实验4：边界样本分析（最接近决策边界的样本）

**目的**：找到那些"勉强"被分类正确的样本，检查是否真的容易区分

**方法**：
1. 训练模型并获取预测概率
2. 找到预测概率接近0.5的样本（边界样本）
3. 分析这些样本的特征分布

**预期结果**：
- ✅ **正常情况**：边界样本很少（< 5%），且特征确实模糊
- ⚠️ **异常情况**：边界样本很多（> 20%），说明模型在"猜"

**代码要点**：
```python
# 获取预测概率
y_proba = model.predict_proba(X)

# 找到边界样本（概率在0.4-0.6之间）
boundary_samples = []
for i in range(len(y)):
    prob = y_proba[i, y[i]]  # 正确类别的概率
    if 0.4 < prob < 0.6:
        boundary_samples.append(i)

print(f"边界样本数量: {len(boundary_samples)} / {len(y)} ({len(boundary_samples)/len(y)*100:.1f}%)")
```

### 实验5：交叉混淆矩阵（类别混淆分析）

**目的**：检查模型是否在某些类别对上更容易混淆

**方法**：
1. 进行多次5折交叉验证
2. 统计每次的混淆矩阵
3. 分析哪些类别对经常混淆

**预期结果**：
- ✅ **正常情况**：混淆矩阵对角线为主，几乎无混淆
- ⚠️ **异常情况**：某些类别对经常混淆（说明特征重叠）

---

### 实验6：特征重要性与模拟参数的相关性

**目的**：检查模型是否学到了模拟器的"作弊"参数

**方法**：
1. 分析特征重要性
2. 检查最重要的特征是否与模拟参数强相关
3. 验证这些相关性是否有物理意义

**检查点**：
- `p_amplitude` 与 `label` 的相关性（模拟器故意设置的）
- `p_noise_level` 与 `label` 的相关性（模拟器故意设置的）
- 这些特征在真实场景中是否存在？

**预期结果**：
- ✅ **正常情况**：特征重要性有物理意义，与真实按摩体验相关
- ⚠️ **异常情况**：特征重要性完全对应模拟器的"作弊"参数
