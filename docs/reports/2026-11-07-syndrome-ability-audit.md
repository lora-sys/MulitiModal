## 1. 宏观指标与统计口径

| 指标 | 值 |
| --- | --- |
| 评估样本数 | 2844（dev 分区全部已标注样本；训练集 40520） |
| Top-1 准确率 | 0.612869 |
| **Top-3 命中率** | **0.843179** |
| Top-5 命中率 | 0.902250 |
| **Macro-F1** | **0.320213** |
| Macro-F1 95% CI | [0.270196, 0.325112]，样本级 bootstrap，n_boot=1000，seed=20261104 |
| Dev 有样本的类别 | 144 / 148 |
| 低样本类别（dev support < 30） | 129 |

口径说明：

- **Macro-F1**：对**全部 148 类**逐类 F1 取算术平均；dev 缺席的 4 类按
  `zero_division=0` 记 F1=0，仍进入分母。这是 Task B 报告 `0.320213` 的来源，
  与 `syndrome.metrics.macro_f1` 逐值一致。
- **Top-3 命中率**：每样本取分数矩阵中最高的 3 类，真值标签命中即计 1
  （`np.argpartition`，平分按索引）；2844 个样本中共 2398 次命中，
  `2398 / 2844 = 0.843179`，与 Task B 一致。
- **逐类 Top-3 命中率**：该类别真实样本中真值进入 Top-3 的比例（recall@3），
  与 Top-1 的 F1 分开报告；另记录 `top3_predicted_count`（该类别出现在任意样本
  Top-3 候选列表中的次数）。
- **拒判统计**：用交付服务 `SyndromeService.analyze_symptoms` 实际跑 dev 文本，
  OK 2562 / UNCERTAIN 282 / ABSTAIN 0 / OUT_OF_DOMAIN 0；拒判率
  `282 / 2844 = 0.099156`，与 Task B 的 `abstain_coverage` 一致。
- **样本守恒核对**：`sum(dev_support) = 2844 = confusion.sum()`，
  `sum(TP) + sum(FN) = 1743 + 1101 = 2844`，
  `sum(TP) + sum(FP) = 1743 + 1101 = 2844`。统计的是**全部评估样本**，
  不是只统计预测正确的样本。
- 索引与名称一致：冻结词表 `syndrome_vocab.txt` 与工件 `labels.json` 顺序完全相同，
  148 个名称唯一，逐类表的 `index` 0–147 与名称一一对应。

## 2. 55 个 F1=0 类别逐一解释

| 分类 | 数量 | 含义 |
| --- | --- | --- |
| 完全没有 dev 样本 | 4 | `血虚证`、`瘀血内阻证`、`脾胃湿热证`、`肠燥津伤证`；F1=0 是 macro 分母口径造成，不代表模型「预测失败」 |
| 有 dev 样本但 Top-1 全部失败 | 51 | 模型从未输出该类为 Top-1（29 类），或曾输出但无一正确（22 类） |
| 其中训练集也无样本 | 0 | 148 类在训练集中均有样本，失败不是「没见过该类」 |
| 同时属于低样本证据不足 | 55 | 全部 55 类 dev support < 30，不能据此断言该类别完全不可用 |

逐类解释（含该类 train/dev support、FP、Top-3 命中数、主要误判类别、证据状态）
写入 `per_class[].zero_f1_reason`、CSV 同名列与 `report.md` 第 2 节。
低样本与「有样本但预测失败」在 `evidence_status` 中分开标记。

## 3. 证据状态与薄弱类别

- 逐类 dev support 中位数 **3**、均值 19.216、最大 543（`气虚血瘀证`）；
  只有 **19 / 148** 类达到 ≥30 样本，只有 **7** 类达到 ≥100。
- 证据状态分布：`LOW_SAMPLE_INSUFFICIENT` 125、`DEV_EVIDENCE_ONLY` 18、
  `WEAK_DEV_EVIDENCE` 1、`NO_DEV_SAMPLES` 4。
- **36 类 F1≥0.5 但 dev support<30，仍被标为证据不足**（例如
  `气虚不摄证` 6 样本 F1=0.571429、`热毒蕴结证` 11 样本 F1=0.7）。
  高分不等于可稳定复现。
- 只有 18 类既有 ≥30 样本又有非零 F1，可称为「开发集内有初步预测证据」；
  这仍不是独立外部验证。
