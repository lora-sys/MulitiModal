## 数据来源

### 波形数据
- **来源**: 增强版数据集（pretrain_10k_enhanced.npz）
- **噪声类型**: 9种（高斯噪声、电磁干扰、接触不良、传感器故障、量化噪声、温度漂移、机械振动、非高斯噪声、数据丢失）
- **处理**: 线性插值修复NaN值、自愈处理

### 静态特征
- **年龄**: 真实用户画像，范围18-100岁，已截断
- **BMI**: 真实用户画像，范围15-40，已截断
- **心率**: 真实用户画像，范围55-170 bpm，已截断
- **血氧**: 真实用户画像，范围95-100%，已截断

### 静态得分
- **健康指数**: 真实用户画像，已归一化
- **诊断得分**: 真实用户画像，已归一化

### 体质
- **类型**: 38种体质类型
- **来源**: 真实用户画像

## 数据格式

### NPZ文件结构

```python
{
    'dynamic': (N, 2, 1000),       # 双通道压力波形
    'static_basic': (N, 4),        # 年龄, BMI, 血氧, 心率
    'static_scores': (N, 2),       # 健康指数, 诊断得分
    'constitution': (N,),          # 体质ID (0-37)
    'labels': (N,)                 # 分类标签 (1-3)
}
```

## 实验追踪

每次实验运行时，会在 `experiment/results/` 目录下创建实验记录：

### 实验记录结构

```
experiment/results/
├── {模型名}/
│   ├── r{运行编号}/
│   │   ├── run_config.json       # 实验配置
│   │   ├── metrics_history.json  # 训练历史
│   │   ├── checkpoints/          # 模型检查点
│   │   └── figures/              # 结果图表
│   │       ├── confusion_matrix.png
│   │       ├── training_curves.png
│   │       └── ...
```

### 配置信息

每次实验记录以下信息：
- 模型类型和融合方式
- 超参数（学习率、批次大小等）
- 数据集配置
- 训练配置（epochs, scheduler等）
- 设备信息
- 随机种子

### 结果记录

- 训练和验证的loss/accuracy历史
- 最终测试结果（准确率、精确率、召回率、F1分数）
- 混淆矩阵
- 训练曲线图
- 模型检查点（最佳模型）
