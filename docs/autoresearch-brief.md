# 研究简报模板

每次研究先填一份简报。已存在冻结协议时引用原始版本，不重新定义它。

| 研究者提供 | 需要写清楚的内容 |
| --- | --- |
| 问题与产物 | 要解决什么问题，产物是什么，什么时候算值得交付 |
| 数据与许可 | 来源、版本和哈希；输入输出；训练、选择、锁定测试的划分和访问权限 |
| 评价 | 基线、固定评价器及其版本、主指标、越大或越小越好、比较和晋级规则 |
| 允许改动 | 唯一可修改文件、允许的依赖与架构；哪些数据、评价和配置冻结 |
| 执行环境 | 运行和记录命令、候选代码的隔离方式、评价器如何与 Agent 隔离 |
| 预算 | 每轮时间、内存/GPU、种子、总轮次或总费用，以及停止条件 |
| 交付与证据 | 代码、配置、日志、实验记录、结果适用范围和需要人判断的事项 |

没有可靠答案的字段写 `UNVERIFIED`；缺少数据权限、评价或隔离条件时不启动真实研究。每轮保留假设、提交、协议标识、结果、决定和失败原因。可复用经验记录其证据与适用条件，独立复现前只称为观察。
