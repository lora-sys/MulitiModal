# AutoResearch 任务立项简报模板

在启动任何新的模型自主探索任务前，研究者必须先填写并固化本简报。已存在冻结协议的研究线直接继承原简报定义，严禁在迭代中随意篡改。

---

## 1. 任务定义表

| 核心维度 | 需明确固化的内容清单 | 填写示例（以体质线为例） |
| :--- | :--- | :--- |
| **科学问题与目标产物** | 要解决的问题本质、目标模型形态、最终交付工件与验收标准 | 274 名受试者 8 维体质评分回归；交付包含模型权重与安全推理接口的持久化工件 |
| **数据源与许可协议** | 数据集名称、来源、版本、文件 sha256 校验和、知识产权许可 | Mendeley `Share data.xls`（sha256: 6206f4...），公开科研学术许可 |
| **划分与权限边界** | 训练集/验证集/测试集划分方案、受试者隔离要求、各集合访问控制 | 严格受试者级 4 折 × 2 次重复；历史 holdout 测试集已耗尽封存，严禁触碰 |
| **固化评价协议** | 评价器入口代码及版本、主评测指标名称与方向（`maximize` / `minimize`）、晋级门槛规则 | `python -m research.constitution`；主指标 `constitution/masked_mae`；严格优于当前 Champion |
| **受约束候选范围** | 探索循环中唯一允许编辑的代码文件路径、允许的依赖范围与架构禁忌 | 唯一允许编辑 `src/research/constitution_train.py`；第 9 维平和质绝不预测（严格 ABSTAIN） |
| **运行时资源预算** | 单折最大时间上限（秒）、可用算力（CPU/GPU）、随机种子、总预算上限与熔断条件 | 单折上限 300 秒；种子固化为 20261105；单轮总训练上限约 40 分钟；超时触发 CRASH |
| **交付物与证据层级** | 最终输出物清单、证据状态标识、外部泛化局限说明 | 交付 Champion Commit、`results.tsv` 实验沿革、验收报告；标为 `LOCAL_EXPERIMENTAL` |

## 2. 填写要求与启动红线

1. **确定性与无歧义**：凡无法确切获知的字段必须显式标注为 `UNVERIFIED` 或 `NOT_AVAILABLE`，严禁含糊其辞或留白。
2. **启动前置检查**：若缺乏确切的数据许可、外部冻结评价器或基本的受试者防泄露边界，严禁启动真实数据实验。
3. **观察与经验的严格区分**：
   - 单轮跑出的高分仅记为**“观察 (Observation)”**；
   - 唯有经过多折检验并在独立环境复现的策略，方可作为**“可靠科研经验”**沉淀入库。
